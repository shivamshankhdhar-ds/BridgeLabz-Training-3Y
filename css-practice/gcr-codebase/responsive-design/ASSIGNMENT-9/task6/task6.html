Responsive CSS Cheat Sheet

Essential concepts for modern web layouts.

Filters

Apply visual effects to images and other elements.

filter: grayscale(100%);

Media Queries

Apply styles based on screen size or device features.

@media (max-width: 700px)

Responsive Design

Make layouts adapt to different screen sizes.

max-width: 100%;

Typography

Scale text smoothly between minimum and maximum sizes.

font-size: clamp(1rem, 3vw, 2rem);

CSS Grid

Create flexible rows and columns for page layouts.

display: grid;

Flexbox

Align and distribute items along a row or column.

display: flex;
