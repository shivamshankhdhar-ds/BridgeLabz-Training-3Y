Responsive Design

Responsive design makes a website adapt to different screen sizes using flexible layouts, CSS Grid, Flexbox, relative units and media queries.

grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

CSS Cheat Sheet

  • Grid: Two-dimensional layouts
  • Flexbox: Alignment and distribution
  • Filters: Visual image effects
  • Media Queries: Screen-based styles
