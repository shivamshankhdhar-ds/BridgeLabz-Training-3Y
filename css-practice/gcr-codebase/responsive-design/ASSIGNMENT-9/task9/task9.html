Principles of Responsive Design

Three important concepts for building flexible websites.

01

Fluid Layouts

Fluid layouts use flexible widths and relative units to adapt content to available screen space. 

.container {
    width: 90%;
    max-width: 1200px;
    margin: auto;
}
02

Flexible Media

Images and other media should resize within their containers without overflowing. 

img {
    max-width: 100%;
    height: auto;
}
03

Breakpoints

Breakpoints use media queries to change the layout when the viewport reaches a specified width. 

@media (max-width: 600px) {
    .container {
        grid-template-columns: 1fr;
    }
}
