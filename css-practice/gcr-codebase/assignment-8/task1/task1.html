What Are Pseudo-Classes?

Pseudo-classes style elements when they are in a particular state, such as being hovered over, focused or clicked.

:hover

Changes an element's style when the pointer moves over it.

Hover over this link

:focus

Highlights an element when it receives keyboard or mouse focus.

:active

Applies a style while an element is being pressed.

:nth-child()

Selects an element based on its position among siblings.

Quick Summary

  • :hover — pointer is over the element.
  • :focus — element has keyboard or input focus.
  • :active — element is being activated or pressed.
  • :nth-child(3) — selects the third sibling element.
