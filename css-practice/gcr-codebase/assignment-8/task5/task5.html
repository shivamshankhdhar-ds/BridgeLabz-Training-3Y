CSS Pseudo-Classes Used

  • :hover — changes appearance when the pointer is over a button.
  • :active — applies an effect while the button is pressed.
  • :focus-visible — highlights a button during keyboard navigation.
  • :disabled — styles a button that is disabled.

Tip: Use the Tab key to navigate between enabled buttons and see the keyboard focus outline.
