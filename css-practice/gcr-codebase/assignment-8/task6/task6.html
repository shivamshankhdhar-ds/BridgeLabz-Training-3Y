CSS Animation Properties

  • @keyframes: Defines the animation steps.
  • animation-delay: Delays the animation start.
  • animation-iteration-count: Sets how many times it repeats.
  • animation-direction: Controls the direction of playback.
  • ease-in-out: Makes movement start and end smoothly.
