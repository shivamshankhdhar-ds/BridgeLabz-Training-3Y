CSS Box-Sizing Comparison

Understand how CSS calculates the total width of an element.

What Is Box-Sizing?

The CSS box-sizing property determines how the declared width and height of an element are calculated.

Compare the Two Boxes

Default Box

box-sizing: content-box;

Content Area

With content-box, the declared width applies only to the content. Padding and borders are added outside.

  • Declared width: 250px
  • Left and right padding: 40px total
  • Left and right border: 10px total
  • Total width: 300px

Border Box

box-sizing: border-box;

Content Area

With border-box, the declared width includes the content, padding and borders.

  • Declared width: 250px
  • Left and right padding: 40px total
  • Left and right border: 10px total
  • Total width: 250px

Key Difference

content-box: Total width = content width + horizontal padding + horizontal borders.

border-box: Declared width already includes horizontal padding and borders.
