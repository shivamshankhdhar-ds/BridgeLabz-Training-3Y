CSS Effects Used

  • :hover — changes styles when the pointer is over an element.
  • :active — changes styles while an element is pressed.
  • :focus-visible — highlights keyboard-focused elements.
  • transition — creates smooth changes between styles.
  • transform — scales or moves an element.
  • box-shadow — adds depth around an element.
