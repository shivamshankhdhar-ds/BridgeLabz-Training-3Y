What is the CSS Box Model?

Every HTML element is represented as a rectangular box. The CSS Box Model consists of content, padding, border and margin.

CONTENT

Four Parts of the Box Model

1. Content

The area where text, images or other content appears.

2. Padding

The space between the content and the border.

3. Border

The line that surrounds the content and padding.

4. Margin

The space outside the border that separates elements.
